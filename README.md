# ChatJFK

ChatJFK is a Retrieval-Augmented Generation (RAG) chatbot designed to answer user queries by retrieving and synthesizing information from the recently released JFK files. The system combines state-of-the-art language models with document retrieval techniques to provide accurate, contextually relevant responses grounded in historical documents.

## Key Features

- **Retrieval-Augmented Generation (RAG):** Combines powerful language models with a document retrieval system to ground responses in real JFK files.
- **Contextual Chatbot:** Users can ask questions about the JFK files and receive answers with references to the source documents.
- **Searchable Corpus:** Efficiently indexes and searches the JFK files for relevant information.
- **Modular Architecture:** Organized into API, scripts, and UI components for easy development and extension.
